# QR & Barcode Generator (CDN-based)

PHP 8.x server-side image storage with browser-side code generation. No Composer, Node.js, downloaded generator libraries, or database required.

## Structure

```text
qr_barcode_api/
├── index.html
├── config.php
├── README.md
├── api/
│   ├── .htaccess
│   └── save-image.php
└── images/
    ├── .htaccess
    ├── qr/
    └── barcode/
```

## How it works

- `index.html` loads QRCode.js from cdnjs and JsBarcode from jsDelivr.
- QRCode.js generates a QR PNG in the browser.
- JsBarcode generates Code 128 SVG in the browser with bar height 50px and width factor 2.
- `api/save-image.php` validates the payload, saves the image to the appropriate directory, and returns JSON with `image_url`.

## Deploy to Hostinger

1. Upload this project folder to your hosting.
2. Edit `config.php`; change `BASE_URL` to the public URL of this folder, without a trailing slash.
3. Make sure `images/qr/` and `images/barcode/` are writable by PHP. Start with 755 and follow your host's recommended ownership/permissions. Do not use 777.
4. Open `https://your-domain/path/index.html` in a browser. Your hosting needs internet access from the visitor's browser for the CDN scripts to load.
5. Generate a QR or barcode and confirm that the returned URL opens the saved image.

## Browser-generated API workflow

This is not a server-side code-generation endpoint accepting only `{ "type": "...", "value": "..." }`. The browser must generate the image first and POST it to:

`POST /api/save-image.php`

QR payload example:

```json
{
  "type": "qr",
  "value": "PROD-2026-0001",
  "image_data": "data:image/png;base64,..."
}
```

Barcode payload example:

```json
{
  "type": "barcode",
  "value": "PROD-2026-0001",
  "image_data": "<svg xmlns=\"http://www.w3.org/2000/svg\" ...>...</svg>"
}
```

The actual image data is generated by QRCode.js or JsBarcode in the browser, not written by hand.

## Response

```json
{
  "success": true,
  "type": "qr",
  "format": "png",
  "value": "PROD-2026-0001",
  "image_url": "https://example.com/qr_barcode_api/images/qr/randomfilename.png"
}
```

## Important limitation

Because the generator libraries run in the browser, an Android/Flutter app cannot simply send `{type,value}` to this PHP endpoint and expect it to create an image. A browser page or a client that runs compatible JavaScript must generate and upload the image. If direct generation from mobile apps is required later, we can add a server-side generator.

## Public endpoint considerations

The save endpoint is unauthenticated by request. It limits request and image sizes, validates PNG/SVG payloads, uses random filenames, and prevents PHP execution in the image folders. Public unauthenticated image creation can still be abused; enable host-level rate limiting/WAF rules and periodically clean old images.
